**Responsável:** Filipe (GP)

## Justificativa de Monitoramento
A adoção das métricas (Burndown Chart e EVM) teve início imediato na Rodada 1, mesmo com o volume inicial de código entregue sendo menor. O monitoramento é um processo contínuo; estabelecer a linha de base (PV) precocemente garante que desvios de cronograma (SPI < 1) ou de custo (CPI < 1) sejam detectados e corrigidos antes de impactarem as entregas futuras.

## EVM (Earned Value Management) - Rodada 1

| Métrica | Descrição | Valor |
|---|---|---|
| **PV (Planned Value)** | Custo planejado para o trabalho agendado. | R$ [X] |
| **EV (Earned Value)** | Valor físico do trabalho realmente entregue. | R$ [Y] |
| **AC (Actual Cost)** | Custo real das horas gastas pela equipe. | R$ [Z] |
| **SPI (EV/PV)** | Índice de Desempenho de Prazo (>1 = adiantado). | [Y/X] |
| **CPI (EV/AC)** | Índice de Desempenho de Custo (>1 = economia). | [Y/Z] |
